# Project description

This project uses the `pbc2` dataset, which contains longitudinal
clinical data from 312 patients with primary biliary cirrhosis (PBC)
included in a randomized Phase 3 Mayo Clinic trial. Several measurements
were collected repeatedly during follow-up, including serum bilirubin,
cholesterol, albumin, alkaline phosphatase, SGOT, platelet count and
prothrombin time. The dataset also contains patient characteristics,
treatment group and clinical outcomes such as survival status or liver
transplantation.

The aim of this project is to evaluate if D-penicil treatment improved
the survival of patients compared to controls.

**Interpretation:**

- data missing per arm : no specific pattern, data missingness not
  related to treatment

- From data missingness per visit : it looks like platelets and alkaline
  have same pattern of missingness, with 2 peaks at visits 11 and 13,
  but stays overall low (max a bit above 12%). For serChol, around 90%
  of patients miss data at visit 2, missingness stay high at several
  visits (above 25% at visits 3-8 ), so missingness is not completely
  random, suggesting a protocol decision (missing by design). Because it
  depends on an observed variable (the visit), it is consistent with
  MAR.

- Data missing per patient state : I plotted the percentage of missing
  data per status and per stage. Higher proportion of missing values for
  dead patients. It is especially obvious for alkaline and platelets. It
  is even more obvious with patient disease severity, where we see for
  alkaline and platelets a strong missingness proportion at stage 4.
  serChol does not follow that logic.

**Conclusion** : serChol has too many missing data, but the missing data
pattern suggests it is MAR. It should be excluded for the longitudinal
analyses. Missingness of alkaline and platelets is associated with
disease severity (histologic stage 4, death), so it is not MCAR. It is
consistent with MAR, but MNAR cannot be excluded.

# 2. Comparison of survival of patients treated with D-penicil vs placebo

To see if the experimental arm (D-penicil-treated patients) obtained
better survival rates than the control arm (placebo patients), I used
Kaplan-Meier curve. I started with censoring, meaning deciding what is
considered as the end of the trial. In our case alive and trasnplanted
were considered as censored, and we counted the number of deaths over
the follow up period.

# 3. Identification of the risk factors at baseline

For this section, I only look at baseline (i.e. the first visit),
ignoring the follow-up visits. To identify which variables are
associated with increase of decrease of death risk (hazard ratio), I
used Cox regression model and plotted the results.

## a. Variable selection

First step is to decide which variables to include in the cox model.
Currently, there are too many variables (15) for 18 coefficients (counts
continuous variable as 1, factors as sum of levels -1 ). As a standard,
I set a minimum of 10 events per coefficients (simulation studies showed
that below this value, the estimates become unreliable (Peduzzi et al.,
1995)).

To reduce the number of coefficients, I used several methods :

1.  **Literature research** to identify which variables have already
    been identified as relevant for PBC prognosis. This exercise is a
    bit tricky here since results from this clinical trial have been
    already published years ago. I therefore used references that date
    before this study (Shapiro et al., 1979, Roll et al., 1983,
    Christensen et al., 1985).

2.  Look at correlations between variables. If variables are strongly
    correlated, they don’t bring new information

3.  Merge categories with a small patient number, since it is hard to
    get reliable analysis results on small N.

### ii. Data imputation and evaluation of the extended model

The extended model includes log(alkaline phosphatase), platelets,
prothrombin time, log(SGOT) and log(serChol) (13 coefficients). SGOT was
moderately correlated with bilirubin (r = 0.59) but kept as a marker of
liver-cell injury.

Since serChol had a quite important number of missing values (9%), I
chose to use mice package (multivariable imputation by chain equations).
Excluding these patients would have reduced the sample and could have
biased the results, since missingness may not be completely random.
Multiple imputation (mice) fills in the missing values several times,
based on the other variables, and combines the results. This keeps all
patients and accounts for the uncertainty of the imputed values.

